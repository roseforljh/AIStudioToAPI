## 代码行为

- 四种 API 协议统一进入现有 Gemini 结构和 MakerSuite 编码器，不按客户端名称添加特殊分支。
- 编码已观察到的 Schema 字段，保留类型联合、用户属性名及工具业务数据；未映射字段忽略，核心字段的类型、范围及必要内容继续校验。
- 空 Struct 工具参数解码为对象；空完成不再伪装成功，而是作为上游错误进入换号重试。
- 缓冲传输使用生成预算，默认 300 秒，避免生成尚未完成就触发旧的 45 秒首次响应超时。非缓冲路径保留原窗口。
- 本次没有承诺未映射的约束、强制工具选择或内置工具在上游执行，也没有实现真正逐 token 生成。

字段依据、源码调用路径及限制见 [Schema 编码说明](makersuite-schema-encoding.md)。
